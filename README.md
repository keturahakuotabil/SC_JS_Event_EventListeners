# Lesson 6: Event Listeners and Web Interactivity

Welcome to Day 6, our final core lesson! Today, we combine everything you have learned about variables, functions, and DOM manipulation to capture real-time actions from users. You will learn to bypass pop-up prompts and handle clicks, typing, and hovers directly inside your web pages.

## ⚠️ Getting Started
1. **Fork** this repository to your personal GitHub account.
2. **Clone** your fork to your computer using `git clone <your-forked-repo-url>`.
3. Complete all tasks locally inside your `script.js` workspace.
4. **DO NOT create a Pull Request (PR)** back to the main repository.

## 📝 Learning Objectives
* Define events, event listeners, and callback response queues.
* Master the syntax layout for the `.addEventListener()` interaction API.
* Intercept click, mouse hover, and live keyboard typed inputs.
* Toggle active structural element variables (like image pathways) in response to user triggers.
* Understand user experience (UX) enhancement styles.

## 🛠️ Classroom Tasks

### TASK 1: Core Concept Evaluation
Examine what an event is and explore the system architecture behind event loops. Review how your browser constantly monitors user movement, tracking exactly when and where input occurs.

### TASK 2: Interactivity Frameworks
Discuss why web events are the backbone of modern web interaction. Analyze the doorbell analogy to solidify how background tracking scripts wake up on command to process specific events.

### TASK 3: Modern Event Registration (.addEventListener)
Deconstruct the syntax format for adding a modern listener loop. Bind a `"click"` event and a `"mouseover"` event to elements to change text messages and swap interface variables instantly without writing code inside your HTML strings.

### TASK 4: Keyboard Input Capture (`keydown`)
Attach a specialized keyboard engine to a text box input layer. Capture characters entered by a user on their keyboard layout in real time using the hidden event object parameters.

### TASK 5: Inline Event Attributes
Explore older historical event approaches like `onclick`, `onmouseenter`, and `onkeydown` placed directly inside HTML tags. Learn why keeping presentation layout sheets isolated from JavaScript code files is the preferred modern development practice.

### TASK 6: Practical Image Toggling
Practice building an operational interactive loop. Use state tracker switches (`true` / `false`) inside a click function to change an image path asset dynamically, creating a working lightbulb simulator.
